# Put your Indian law PDF files here

## Required PDFs

Add the following legal document PDFs to this folder:

1. **IPC.pdf** - Indian Penal Code, 1860
2. **CrPC.pdf** - Code of Criminal Procedure, 1973
3. **Motor_Vehicles_Act.pdf** - Motor Vehicles Act, 1988
4. **Consumer_Protection_Act.pdf** - Consumer Protection Act, 2019
5. **Negotiable_Instruments_Act.pdf** - Negotiable Instruments Act, 1881
6. **Industrial_Disputes_Act.pdf** - Industrial Disputes Act, 1947

## How to Add PDFs

1. Download the official PDF versions of these acts
2. Copy them to this directory
3. Run the server - it will automatically upload them to Gemini and create a cache

## Notes

- PDFs will be automatically detected and uploaded when the server starts
- The cache lasts for 2 hours, then refreshes automatically
- Larger PDFs may take longer to upload
- Ensure PDFs are text-searchable (not scanned images)
